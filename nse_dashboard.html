API Docs — how to use this server from other applications

Base URL: http://<host>:8910 (local: http://127.0.0.1:8910, LAN: http://192.168.1.33:8910). CORS is open, so browser apps on any origin can call it.

EndpointDescription
GET /api/option-chainOption chain w/ IV + delta/gamma/vega per option
GET /api/expiriesLive expiry dates for a symbol (settled expiries skipped)
GET /Dashboard (this page)
GET /playgroundInteractive API playground
GET /docsFastAPI auto-generated OpenAPI docs
Query paramValuesDefault
symbolNIFTY, BANKNIFTY, FINNIFTY, MIDCPNIFTY, NIFTYNXT50, or equity symbol (RELIANCE, …)NIFTY
typeIndices | EquitiesIndices
expirye.g. 17-Nov-2026; omit for latest live expirylatest live

Examples

cURL:

curl "http://127.0.0.1:8910/api/option-chain?symbol=NIFTY&expiry=17-Nov-2026"

JavaScript (fetch):

const res = await fetch("http://127.0.0.1:8910/api/option-chain?symbol=NIFTY");
const data = await res.json();
data.meta            // { symbol, type, expiry, underlying_value, timestamp, strikes }
data.records[0]     // { strike_price, expiry, dte_days, ttm_years, ce, pe }
data.records[0].ce  // { ltp, oi, chg_oi, volume, bid, ask, iv, iv_source, delta, gamma, vega }

cURL (expiries):

curl "http://127.0.0.1:8910/api/expiries?symbol=NIFTY"

Each CE/PE object contains iv (NSE / solved-from-LTP / interpolated / approx-cross-expiry, flagged by iv_source) plus delta, gamma, vega. Requesting a settled (expired) expiry returns HTTP 422 with an explanation.
